# 中国管制/制裁清单检索路径（无接口场景）

> 一个 WorkBuddy Skill —— 教你如何核查**中国官方那些"没有查询接口"的制裁与出口管制清单**。

**一句话**：OFAC、欧盟那些清单能直接下 CSV 拉下来比对，但中国的清单不给 API、不给数据下载。本 skill 把"只能人工检索"这条路沉淀成标准 SOP。

---

## 什么时候需要它

✅ 需要
- 供应商准入 / 交易对手筛查，要核查对方是否被中国官方列入限制名单
- 收到"中国清单没有 API 怎么查"这类问题
- 有历史核查结论，需要**复核**是否仍然成立

❌ 不需要
- 美、欧、联合国、英、日等**有可机读下载接口**的清单 —— 直接拉 csv/xml 做自动比对更快更准

> 配套：`cn-sanctions-sources`（官方源索引）／`cn-sanctions-screening`（境外有接口清单的自动筛查）。本 skill 只补"中国无接口清单"这一段。

---

## 覆盖范围：中国 4 张可按名称筛查的清单

### 经济制裁类（3 张）

| 清单 | 管理机关 | 依据 | 措施 |
|---|---|---|---|
| **不可靠实体清单** | 商务部工作机制 | 《不可靠实体清单规定》＋对外贸易法＋国家安全法 | 禁对华进出口、禁在华新增投资、禁高管入境、取消高管居留许可、**处两倍罚款** |
| **反制清单** | 外交部 | 《反外国制裁法》 | 冻结境内财产、禁境内主体交易合作；对个人还含不予签发签证、不准入境 |
| **恶意实体清单** | 国务院 | 《反外国不当域外管辖条例》（2026-04-07 生效） | 反制和限制措施；**首批名单状态须每次核查时确认** |

### 出口管制类（1 张）

| 清单 | 管理机关 | 依据 | 措施 |
|---|---|---|---|
| **出口管制管控名单** | 商务部 | 《出口管制法》＋《两用物项出口管制条例》 | 禁止向其出口两用物项、在跑出口停止、特殊情况报商务部申请 |

### 不适用
- **两用物项和技术管制清单** —— 物项/法规清单，列的是受管制**物项**而非主体，按物项归类（ECCN 类比）处理，不做名称比对。

> ⚠️ **最容易搞错的一点**：在"出口管制管控名单"里，"两用物项"指的是**被限制的内容**，而清单列的**仍然是实体**，所以可以按名称筛查。别因为名字里有"两用物项"就把它归到物项清单里。

## 标准流程（五步）

1. **定位权威来源** —— 搜索引擎只作引线，**结论必须回官网正文核实**
2. **定位公告/名单正文** —— 按时间倒序，区分"法规"与"名单公告"
3. **进入正文提取名单** —— 注意分页、折叠、JS 渲染
4. **名称比对** —— 法人颗粒度 ＋ 双语 ＋ 归一化
5. **截图留痕** —— 列表页 ＋ 正文页各一张

另附**执行检查清单**（10 项打勾防漏步）与**复核流程**（结论有时效，须定期重跑）。

### 官方入口
| 用途 | 入口 |
|---|---|
| 出口管制/不可靠实体清单公告索引（**首选**） | `exportcontrol.mofcom.gov.cn` |
| 商务部政府信息公开 | `mofcom.gov.cn` |
| 外交部反制决定及附件清单 | `mfa.gov.cn` |

## 三个最容易踩的坑

**1. 法人颗粒度（最高频误判）**
清单对象是**法人**，不是集团。同一集团的不同法人可能落在不同清单，母公司往往未被列。
> 实例：`波音防务、空间与安全集团`（不可靠实体清单＋出口管制管控名单）与 `波音密苏里州圣路易斯市分公司`（反制清单）是**两个不同法人**，而 **The Boeing Company 母公司未列入任何清单**。用"波音"简称下结论会同时造成误报与误判。

**2. 名称是「中文名（英文名）」双语**
中英文名**各比对一次**。只有英文名时直接做英文子串比对，**不必先音译**（音译会引入漏检）。比对前须归一化（大小写、标点、公司后缀），否则 `AERKOMM INC.` 与 `Aerkomm Inc.` 会漏。

**3. 未见名单 ≠ 未命中**
制度已生效但名单尚未发布时，记录"条例已生效、首批未发布"，**不判"未命中"**。

## 配套脚本

`scripts/match_names.py` —— 名称归一化 ＋ 精确命中 ＋ bigram 候选标记（纯标准库）

```bash
python scripts/match_names.py --names names.txt --list extracted.txt
python scripts/match_names.py --names names.txt --list extracted.txt --out report.md
```

## 重要提醒

- **本 skill 输出的是事实核查，不是法律意见**，不构成合规结论。
- **结论仅对核验日有效**。清单不定期更新，务必按 `references/recheck.md` 定期复核（建议月度）。
- **模糊命中必须人工终判**并二级复核，脚本只做辅助标记。
- **跨境交易还需核查其他管辖区**（走 `cn-sanctions-screening`）。
- 本 skill 只索引/摘录官方源，**不建受制裁主体数据库**。
