# 中国管制/制裁清单检索路径（无接口场景）

> 一个 WorkBuddy Skill —— 把"只能人工检索"这件事，做成一套可复核、可留痕、可交接的流程。

中国的制裁与出口管制清单**不给 API、不给数据下载**。OFAC、欧盟那些能直接拉 CSV 批量比对的清单，中国没有。所以现实做法是人工检索——而人工检索最容易出三个问题：

**漏了某张清单** · **名称对错了** · **事后拿不出证据**

这个 skill 就是来解决这三件事的。

---

## 它做什么

给它一个公司名，它会带你走完：

**① 固定核查顺序** → **② 回官网正文核实** → **③ 归一化比对** → **④ 身份交叉核验** → **⑤ 截图留痕** → **⑥ 定期复核**

最后产出一份**可直接入档的核查记录**：逐清单结论 ＋ 公告文号 ＋ 双截图 ＋ 历次复核记录。

### 已跑通的真实案例

| 案例 | 核查结果 | 沉淀进了什么 |
|---|---|---|
| **Aerkomm Inc.**（只有英文名） | 命中**不可靠实体清单** ＋ **反制清单**，措施为禁对华进出口、冻结境内财产 | **双语各比对一次**——只有英文名时直接做英文子串比对，**不必先音译**（音译反而漏检） |
| **波音防务**（同集团多法人） | **波音防务、空间与安全集团**命中不可靠实体清单＋出口管制管控名单；**波音密苏里州圣路易斯市分公司**另在反制清单；**母公司 The Boeing Company 未列入任何清单** | **法人颗粒度**——结论必须写清命中的是哪个法人，以及母公司是否在列 |

两个案例的完整留痕（结论、文号、措施、截图）都在 `references/` 里，可以直接看它怎么落地。

---

## 什么时候用它

**适合**
- 供应商准入 / 交易对手筛查，核查对方是否被中国官方列入限制名单
- 需要一份能拿给审计、内部合规或监管看的核查记录
- 已有历史结论，要**复核**是否仍然成立
- **中小体量交易对手与重点高风险主体的单点核查**——这正是它的主场

**用不上的地方**
- 美 / 欧 / 联合国 / 英 / 日等**有可机读接口**的清单：直接拉 csv/xml 批量比对更快更准，走 `cn-sanctions-screening`
- **数万主体的大规模批量筛查**：那需要自动化工具，人工 SOP 成本上做不动

> **配套关系**：`cn-sanctions-sources`（官方源索引）／`cn-sanctions-screening`（境外有接口清单的自动筛查）／本 skill（中国无接口清单的人工检索 SOP）。
> ⚠️ **二者互补，不是替代**——境外走自动筛查，中国无接口清单走本 skill，跨境交易须两段都做。

## 覆盖的清单：4 张以主体名称列名的清单

### 经济制裁类（3 张）

| 清单 | 管理机关 | 依据 | 措施 |
|---|---|---|---|
| **不可靠实体清单** | 商务部工作机制 | 《不可靠实体清单规定》＋对外贸易法＋国家安全法 | 禁对华进出口、禁在华新增投资、禁高管入境、取消高管居留许可、**处两倍罚款** |
| **反制清单** | 外交部 | 《反外国制裁法》 | 冻结境内财产、禁境内主体交易合作；对个人还含不予签发签证、不准入境 |
| **恶意实体清单** | 国务院 | 《反外国不当域外管辖条例》（2026-04-07 生效） | 反制和限制措施；**首批名单状态须每次核查时确认** |

### 出口管制类（1 张）

| 清单 | 管理机关 | 依据 | 措施 |
|---|---|---|---|
| **出口管制管控名单** | 商务部 | 《出口管制法》＋《两用物项出口管制条例》 | 禁止向其出口两用物项、在跑出口停止、特殊情况报商务部申请 |

> ⚠️ **最容易搞错的一点**：在"出口管制管控名单"里，"两用物项"指的是**被限制的内容**，而清单列的**仍然是实体**，所以可以按名称筛查。别因为名字里有"两用物项"就把它归到物项清单里。

### 核查顺序（固定，四张一张不落）

**① 不可靠实体清单 → ② 出口管制管控名单 → ③ 反制清单 → ④ 恶意实体清单**

效力最强的排在最前；第 ①② 张同属商务部，一次检索即可覆盖。

### 官方入口

| 清单 | 入口 | 注意事项 |
|---|---|---|
| 不可靠实体清单 | 商务部 `mofcom.gov.cn`；**首选** `exportcontrol.mofcom.gov.cn` | 站内搜索常只返回摘要，须点进正文 |
| 出口管制管控名单 | `exportcontrol.mofcom.gov.cn`；商务部 `mofcom.gov.cn` | 与不可靠实体清单同机关，可一并检索 |
| 反制清单 | 外交部 `mfa.gov.cn`（新闻 → 反制决定 ＋ 附件《反制清单》） | 随新闻以"决定＋附件"发布，不单独成栏目 |
| 恶意实体清单 | 国务院 `gov.cn` | 须先确认是否已发布首批名单 |

## 标准流程

1. **定位权威来源** —— 搜索引擎只作引线，**结论必须回官网正文核实**
2. **定位公告/名单正文** —— 按时间倒序，区分"法规"与"名单公告"
3. **进入正文提取名单** —— 注意分页、折叠、JS 渲染
4. **名称比对** —— 法人颗粒度 ＋ 双语 ＋ 归一化 ＋ 身份交叉核验
5. **截图留痕** —— 列表页 ＋ 正文页各一张

另附**执行检查清单**（10 项打勾防漏步）与**复核流程**（建议月度复核）。

### 第 4 步必做：身份交叉核验
名称匹配**不等于**主体同一——两个同名主体都会误命中。凡出现命中或候选，须用下列辅助信息**至少核验两项一致**：

- 主体识别码：境内**统一社会信用代码**；境外注册号／公司号／LEI／税号
- 注册地／注册地址、成立日期
- 经营范围、行业、规模、官网与邮箱域名
- 母子公司与集团结构（区分母公司、子公司、分公司）

不一致 ⇒ 判"非同一主体"，按未命中处理并写明排除理由；信息不足以排除同名 ⇒ 保持"候选"，不定性为命中。

### 风险分级：决定深度与留痕，不决定查哪几张
⚠️ **四张永远全查**，分级只调整检索深度、留痕等级与复核强度——避免因风险判断失误而漏查某张清单。

| 项 | 高风险 | 低风险 |
|---|---|---|
| **清单范围** | **4 张全查** | **4 张全查** |
| 留痕 | 全套留痕 ＋ 双截图 ＋ 二级复核 | 最小证据留痕（清单、文号、访问日期、结论） |
| 复核 | 月度 | 月度 |

**高风险判定**（满足任一）：涉两用物项／军民两用技术；涉台军售或涉台业务；新建立关系；位于高风险管辖区或曾被列任何名单；管理层关注、金额重大、有负面涉华报道。
**升级机制**：一旦出现候选／近似项、新增敏感物项、外部信息负面变化 ⇒ 立即升为高风险重做。留痕须记**分级结论、依据、分级人**。

### 留痕模板
`references/record-keeping.md` 提供三套：
- **首次核查记录**（逐清单结论表 ＋ 同名主体甄别表）
- **阴性结果记录模板** —— "未命中"必须单独举证：四张逐一写明"已核查＋文号＋名单发布日＋结论"
- **截图要点清单** —— 截图须可见 URL、机关、文号、发布日期、主体所在段落、官网页脚

## 三个最容易踩的坑

**1. 法人颗粒度（最高频误判）**
清单对象是**法人**，不是集团。同一集团的不同法人可能落在不同清单，母公司往往未被列。用"波音"这种简称下结论，会同时造成误报与误判。

**2. 名称是「中文名（英文名）」双语**
中英文名**各比对一次**；只有英文名时直接做英文子串比对，不必先音译。比对前须归一化（大小写、标点、公司后缀），否则 `AERKOMM INC.` 与 `Aerkomm Inc.` 会漏。

**3. 未见名单 ≠ 未命中**
制度已生效但名单尚未发布时，记录"条例已生效、首批未发布"，**不判"未命中"**。

## 配套脚本

`scripts/match_names.py` —— 名称归一化 ＋ 精确命中 ＋ bigram 候选标记（纯标准库）

```bash
python scripts/match_names.py --names names.txt --list extracted.txt
python scripts/match_names.py --names names.txt --list extracted.txt --out report.md
```

⚠️ 脚本只做名称字符串匹配，**不含主体身份信息，无法识别同名主体**，输出作为候选线索，主体同一性由人工核验。

## 结论怎么读才对（合规要点）

这一节决定你会不会误用它的产出。

- **"未列入" ≠ "不受限制"。** 清单核查通过，只能证明该主体**不在公开名单上**。部分限制措施**根本不会出现在任何公开清单里**——个案决定、针对特定交易的禁令、未公开的监管措施。**阴性结果必须停在事实层面，不要读成"无风险"。**
- **阴性结果也要举证。** 命中有公告为证；"已查未发现"只写两个字等于没查。四张清单要逐一留下文号与访问日期。
- **这不是法律意见。** 本 skill 产出的是"是否出现在官方名单"的事实核查，不构成合规结论。重大交易仍需法律专业判断，必要时走管理机关对外咨询渠道。
- **跨境交易还需核查其他管辖区**，走 `cn-sanctions-screening`。

### 覆盖范围之外
中国另有限制分散在其他制度与主管部门，**均不在本 skill 范围内**，须另行核查：

| 类型 | 归口 |
|---|---|
| 物项类管制（两用物项和技术管制清单——按物项归类 / ECCN 类比，不做名称比对） | 商务部／海关总署 |
| 外商投资安全审查 | 外商投资主管部门 |
| 行业专项限制名单（国防科工、生态环境、药监等各自的管理名单） | 各行业主管部门 |
| 不当域外管辖相关措施（禁执令、阻断措施等） | 《反外国不当域外管辖条例》体系 |
| 境外清单 | 走 `cn-sanctions-screening` |
