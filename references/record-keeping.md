# 合规留痕模板

中国无接口清单核查完成后，按以下结构留存记录，满足合规可追溯要求。每一条核查单独成档；复核记录**追加**在首次记录之后（模板见 `recheck.md`）。

## 一、单条核查记录（首次）

| 字段 | 内容 |
|------|------|
| 核查日期 | YYYY-MM-DD（即"结论有效日"） |
| 核查用途 | 供应商准入／交易审查／内部备案／监管问询 |
| **法人全称** | 清单命中的**完整法人名称**（中文全称＋英文全款并列） |
| 名称完整性 | 完整／仅核中文名／仅核英文名／简称（**需确认**） |
| 母公司是否在列 | 是／否／未知（集团内法人须逐一说明） |
| 查询对象补充 | 曾用名、别名、个人姓名（若涉及高管） |
| 目标清单 | 不可靠实体清单／反制清单／恶意实体清单／出口管制管控名单 |
| 管理机关 | MOFCOM／MFA／国务院 |
| 源 URL（列表页） | https://… |
| 源 URL（正文页） | https://… |
| 名单版本/发布日期 | 公告文号＋发布日期（区分**名单版本日**） |
| 比对结果 | 命中／未命中／候选（近似，待人工终判）／**未见名单**（制度已生效待发布） |
| 措施摘要 | 按公告原文列全（是否含罚款、禁高管入境、禁新增投资等） |
| 候选说明 | 若为候选，写明近似点与不确定性 |
| 截图路径 | 本地截图（列表页＋正文页各一） |
| 操作人 | 姓名/工号 |
| 复核人 | 姓名（模糊命中须二级复核） |
| 复核建议 | 下次复核日期（建议月度） |

## 二、复核记录区块（追加，不覆盖）

| 字段 | 内容 |
|------|------|
| 复核日期 | YYYY-MM-DD |
| 复核结论 | 维持／变更／新增命中／已移出／仍待发布 |
| 变化说明 | 新增、移出或措施调整＋对应公告文号 |
| 当前措施 | 按最新公告原文列全 |
| 复核人 | 姓名 |
| 业务通知 | 是否已通知业务方＋日期 |

## 三、留痕要点
- **双截图**：栏目列表页 + 公告正文页，均含 URL、访问时间、名单版本日期。
- **双日期分清**：**名单版本日**（公告发布日）与**核验日**（访问日）不得混用。
- **法人全称必写**：结论须写明命中的是哪个法人全称，并说明母公司是否在列（见 `example-boeing.md`）。
- **结论带时效**：明确"截至 YYYY-MM-DD 未在官方名单发现"，不含"永久安全"类绝对表述。
- **模糊即候选**：任何近似/变体一律标"候选"，不写"命中"，交人工终判并二级复核。
- **措施列全**：不可靠实体清单可能含**禁止高管入境**、**罚款**等，不能只写"禁止交易"。
- **区分"未见名单"与"未命中"**：前者是制度已生效但名单未发布，不得判为"未命中"。
- **可追溯**：截图与记录同档保存，历次复核追加留存，便于审计或监管调阅。
- **不仓储全量名单**：仅保留本次核查所需摘录，不建私有受制裁主体数据库。
- **非法律意见**：记录末尾注明本记录为事实核查，不构成合规结论或法律意见。
