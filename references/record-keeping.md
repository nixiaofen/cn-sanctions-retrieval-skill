# 合规留痕模板

中国无接口清单核查完成后，按以下结构留存记录。**每一条核查单独成档**；复核记录**追加**在首次记录之后（见 `recheck.md`）。

---

## 一、首次核查记录

### 1.1 基本信息
| 字段 | 内容 |
|------|------|
| 核查日期 | YYYY-MM-DD（**核验日**，结论有效日） |
| 核查用途 | 供应商准入／交易审查／内部备案／监管问询 |
| 风险分级 | 高风险／低风险（附分级依据与分级人） |
| **法人全称** | 清单比对的**完整法人名称**（中文全称＋英文全称并列） |
| 名称完整性 | 完整／仅核中文名／仅核英文名／简称（**需确认**） |
| 母公司是否在列 | 是／否／未知（集团内法人须逐一说明） |
| 查询对象补充 | 曾用名、别名、相关个人姓名（若涉高管） |

## 二、阴性结果记录模板（"未命中"必须单独举证）

**为什么单独设模板**：合规上，**举证"没有"比举证"命中"更难**。命中时有公告为证；但"已查、未发现"如果只写两个字，事后无法证明查全了。**阴性结果必须与阳性结果同等留痕。**

| 字段 | 内容 |
|------|------|
| 核查对象（法人全称） | |
| 核查日期（核验日） | YYYY-MM-DD |
| 风险分级 | 高／低 |
| **逐清单核查声明** | 下方四行**必须全部填写**，空缺即视为核查不完整 |
| ① 不可靠实体清单 | 已核查　最新公告文号：＿＿＿　名单发布日：＿＿＿　结论：**未见列入** |
| ② 出口管制管控名单 | 已核查　最新公告文号：＿＿＿　名单发布日：＿＿＿　结论：**未见列入** |
| ③ 反制清单 | 已核查　最新决定文号：＿＿＿　决定日期：＿＿＿　结论：**未见列入** |
| ④ 恶意实体清单 | 已核查　制度状态：＿＿＿　结论：**未见列入**／**尚未发布首批名单（待更新）** |
| 已比对名称 | 中文名：＿＿＿　英文名：＿＿＿（**两种语言均须比对**） |
| 同名排除说明 | 若存在同名主体，写明如何排除：＿＿＿（无则填"无同名情形"） |
| 证据 | 截图编号：＿＿＿（至少覆盖公告正文页） |
| 操作人／复核人 | |
| **结论表述（照此写）** | "截至 YYYY-MM-DD，经核查上述四张官方清单，**未发现**该主体被列入。"（**不得写"无风险""合规""安全"**） |

> ⚠️ 若某张清单尚未发布首批名单（如恶意实体清单），**只能写"尚未发布首批名单、待持续更新"，不得写"未命中"**。

## 三、截图要点清单

每张截图必须**肉眼可读**地体现以下要素，缺一不可：

| # | 要点 |
|---|---|
| 1 | **浏览器地址栏 URL**（完整可见，证明是官网而非转载站） |
| 2 | **页面/公告标题** |
| 3 | **发布机关**（商务部／外交部／国务院） |
| 4 | **公告文号**（如"不可靠实体清单工作机制公告〔2024〕2号"） |
| 5 | **发布日期**（名单版本日，与核验日区分） |
| 6 | **名单正文中被比对主体所在段落**（需能看清名称与上下文） |
| 7 | 官网标志性页脚（如网站标识码、ICP 备案等，便于辨真伪） |

- 阳性命中：**列表页 ＋ 正文页**双截图。
- 阴性未命中：至少留**正文页**截图（证明确实查过这一张）。

## 五、留痕要点
- **双日期分清**：**名单版本日**（公告发布日）与**核验日**（访问日）不得混用。
- **法人全称必写**：结论须写明命中的是哪个法人全称，并说明母公司是否在列。
- **措施列全**：不可靠实体清单可能含**禁止高管入境**、**取消居留许可**、**罚款**等，不能只写"禁止交易"。
- **区分"未见名单"与"未命中"**：前者是制度已生效但名单未发布，不得判为"未命中"。
- **阴性结果同等留痕**：见第二节模板。
- **不得写绝对化表述**：禁止"无风险""安全""合规"等结论性措辞，只陈述"是否出现在官方名单"。
- **可追溯**：截图与记录同档保存，历次复核追加留存，便于审计或监管调阅。
- **不仓储全量名单**：仅保留本次核查所需摘录，不建私有受制裁主体数据库。
- **非法律意见**：记录末尾注明本记录为事实核查，不构成合规结论或法律意见。
