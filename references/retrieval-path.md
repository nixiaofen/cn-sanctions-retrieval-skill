# 各中国清单的检索路径与坑点

本文件给出 4 张"无接口"、可按名称筛查的中国清单的分站点检索步骤、官方入口与坑点。**结论以官网正文为准，搜索引擎仅作引线。**

## 通用路径（适用于全部 4 张）
1. 用搜索引擎或官网检索定位公告（**仅作引线**）。
2. **回官网正文核实**（转载站易漏文、缺附件、过期）。
3. 按时间倒序定位最新公告；区分"规定/办法"（法规）与"具体名单公告"（实体列表）。
4. 提取正文实体名称（中文名 ＋ 并列英文名）。
5. 归一化后做双语比对 → 截图留痕。

**推荐官方入口**
- 中国出口管制信息网：`exportcontrol.mofcom.gov.cn`（出口管制与不可靠实体清单公告索引，检索友好，首选）
- 商务部政府信息公开：`mofcom.gov.cn`
- 外交部：`mfa.gov.cn`

## 一、经济制裁类（3 张）

### 1. 不可靠实体清单（Unreliable Entity List）
- 管理机关：商务部不可靠实体清单工作机制
- 官网：`mofcom.gov.cn`；**出口管制信息网**有对应栏目（检索更友好）
- 依据：《不可靠实体清单规定》＋对外贸易法＋国家安全法＋反外国制裁法
- 检索逻辑：检索"不可靠实体清单"，找最新一期**名单公告**（正文列被列实体中文名＋英文名）。
- 措施：禁止从事与中国有关的进出口活动；禁止在中国境内新增投资。
- 坑点：站内搜索常只返回摘要，须点进正文取完整名单；名单公告与《规定》本身易混排，先确认是"具体名单"。

### 2. 反制清单（Counter-Sanctions List）
- 管理机关：外交部
- 官网：`mfa.gov.cn`（"新闻"→反制决定公告，含附件《反制清单》）
- 依据：《中华人民共和国反外国制裁法》
- 检索逻辑：检索"反制"或"反制清单"，找附《反制清单》的决定；清单逐条列中文名＋英文名。
- 措施：冻结其在我国境内的动产、不动产和其他财产；禁止我国境内组织、个人与其进行交易、合作。
- ⚠️ **对象含自然人**：决定表述为"企业**及相关高级管理人员**"，须**同时用个人姓名筛查**。
- 坑点：反制清单常随新闻以"决定＋附件"形式发布，不单独成栏目；措施描述较长，提取被列对象时须剥离措施文字、只留名称。

### 3. 恶意实体清单（List of Malicious Entities）
- 管理机关：国务院
- 官网：`gov.cn`
- 依据：《反外国不当域外管辖条例》（2026-04-07 公布并施行）
- 制度意义：创设**恶意实体清单**制度，针对"推动实施或参与实施外国不当域外管辖措施"的外国组织、个人。
- ⚠️ **首批名单状态须每次核查时确认**（截至 2026-10-11 尚未发布）。查核时若查无数据，记录"**条例已生效、首批未发布**"，**不判"未命中"**，纳入持续监控；一旦发布，本节须更新。
- 坑点：新制度、发布节奏不确定，需持续留意更新。

## 二、出口管制类（1 张）

### 4. 出口管制管控名单
- 管理机关：商务部
- 官网：`mofcom.gov.cn`；出口管制信息网有对应栏目
- 依据：《出口管制法》＋《两用物项出口管制条例》
- 检索逻辑：检索"出口管制管控名单"，找列入公告；正文/附件列被列实体（中文名＋英文名）。
- 措施：禁止向名单实体**出口两用物项**；在跑的出口活动应立即停止；特殊情形须向商务部申请。
- ✅ **这是实体名单，可按名称筛查**——"两用物项"是**被限制的内容**，不是清单的对象类型。
- ⚠️ **与不可靠实体清单同日发布的坑**：商务部曾于**同一日**发布两批不同企业，一批进不可靠实体清单、一批进出口管制管控名单。务必确认实体落在哪一张，两者法律后果完全不同。

### 附：不适用本路径的两用物项和技术管制清单
- 商务部/海关，列的是**受管制物项与法规**，非主体名单；按物项归类/ECCN 类比处理，不做名称比对。

## 常见坑点汇总
- **⚠️ 法人颗粒度（最高频误判）**：清单对象是**法人**，不是集团。同一集团的不同法人可能落在**不同**清单，母公司往往未被列。例：`波音防务、空间与安全集团`（不可靠实体清单＋出口管制管控名单）与 `波音密苏里州圣路易斯市分公司`（反制清单）是两个不同法人，The Boeing Company 母公司未列 → 不得用"波音"简称下结论。
- **措施不只"禁止交易"**：不可靠实体清单可能含**禁止高管入境**、**取消高管居留/工作许可**、**处两倍罚款**等，须按公告原文列全。
- **名称是双语标注**：正文多为「中文名（英文名）」。必须中英文名各比对一次；仅有英文名时直接做英文子串比对，**不要先音译**（音译易错且漏检）。
- **先归一化**：统一大小写/标点空白，剥离 `Inc.` `Co.` `Ltd.` `公司` `有限公司` 等后缀，否则 `AERKOMM INC.` 与 `Aerkomm Inc.` 漏检。
- **含自然人**：反制清单含"相关高级管理人员"，别只查企业名。
- **同一实体可跨清单**：如英特磊公司同在出口管制管控名单与反制清单；各清单后果不同，必须逐清单分别记录。
- **经济制裁 ≠ 出口管制**：法律依据与限制内容都不同，须分别核查、分别表述。
- **同日双公告**：见上文"出口管制管控名单"坑点。
- **未见名单 ≠ 未命中**：见"恶意实体清单"时效说明。
- **JS 动态渲染**：名单由前端异步加载，脚本直连拿不到 → 改用浏览器或 WebFetch。
- **分页/折叠**：长名单分多页或折叠，需展开全部再截取。
- **编号列表**：名单常为"1. 2. 3."编号项，提取时保留序号以便引用（如"第5项"）。
- **转载站不可信**：结论必须回官网正文核实。
- **时效性**：结论仅对核验日有效；须区分**名单版本日**（公告发布日）与**核验日**（访问日）。
